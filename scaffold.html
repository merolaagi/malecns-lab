A learner built from the fly's design, sparse codes and reference frames

Fly connectome: a sparse expansion (measured projection-neuron → Kenyon-cell wiring), one-shot memory written only on active cells, and a reference frame that adds up movements. HTM: codes are sparse distributed representations, and cells predicted by the previous step get a head start (Byrne's prediction-assisted pooling). Monty: features stored at locations, recognised by moving a sensor, with modules voting. The question is how little data it needs, against standard learners trained on the same data.

Measured: the projection-neuron → Kenyon-cell wiring. Assumed: everything else (pixel-to-input assignment, 5% sparsity, the learning rules, the tasks, the reference-frame geometry). In the arithmetic test the frame is given a line; what is learned is which symbol sits where. Three seeds throughout.
