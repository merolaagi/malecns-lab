Seeing a cup, remembering it, recognising a different one

An object is rendered, sampled by 721 eye columns, contrast-adapted as in the lamina, pooled by visual projection neurons, sparsely coded by the visual Kenyon cells (KCg-d, KCab-p), and stored by dopamine in mushroom-body compartments. Then the fly sees new lighting, new distances and new kinds of cup.

Measured: Kenyon cells, output and dopamine neurons, compartments and their edges; the visual inputs onto Kenyon cells once build_visualmemory.py has run (until then a random stand-in, flagged above). Assumed: the objects and renderer, the lamina model, each input's feature channel and receptive field, the sparseness, and the memory model's rules. Vision is monochrome here. Not Monty: nothing builds an object-centred reference frame. Extra glimpses add evidence; they don't assemble a model of the object.
