How a fly remembers an odour

Memory written where Kenyon-cell activity meets dopamine in a mushroom-body compartment, kept as a labile and a consolidated trace, read out through the balance of output neurons, and countered by extinction through the loops back onto dopamine neurons.

The wiring decides where memory can be written; the model decides how. Every cell, compartment and edge comes from data/mushroom-body.json. Assumed: the learning rule and its rates and time constants, the consolidation rule, PAM cells as rewarding and PPL1 cells as punishing (the real fly has exceptions), output-neuron valence derived from each compartment's teachers, random odour codes, and the behavioural readout. A connectome cannot show what this fly remembers; it shows where a memory could be stored.
