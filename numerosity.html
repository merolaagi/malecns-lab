Which number is larger?

Numbers become patterns on 314 measured projection neurons, pass through the measured PN → Kenyon cell wiring, and a plastic readout learns to pick the larger of two. Some numbers are never shown in training.

A test of the code, not of fly arithmetic. Every number switches on exactly 30 PNs, so total activity carries no size cue. The scalar code gives neighboring numbers overlapping PNs, as in an HTM scalar encoder. The one-hot code gives each number its own PNs. Any success on held-out numbers must come from that overlap. Chance is 50%.

What’s measured and what’s assumed

Measured: PN → KC edges and synapse counts, KC → MBON edges, PAM → KC synapse totals used as a learning gate.

Assumed: the number codes and the random PN order they use, noise level, the 95th-percentile Kenyon cell threshold, the pooled value readout, and feedback to both options each trial (+1 for the larger, −1 for the smaller). With feedback only to the chosen option, values drift toward “good whenever I picked it” and no ordering forms.
