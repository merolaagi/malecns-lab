Learning new classes without forgetting old ones

A fly-inspired design tested as a machine-learning component: expand the input into thousands of units, keep only the 5% most driven, and let a reward signal strengthen only the correct class's connections. Classes arrive a few at a time, and there is no task label at test time.

Borrowed, then tested against controls. The expansion uses the measured MaleCNS projection-neuron → Kenyon-cell wiring. Pixels drive projection neurons through a fixed random assignment, and the task is handwritten digits, which flies obviously don't read. Every fly-derived part is compared with shuffled wiring, random wiring, no expansion, and standard backpropagation.

What the controls show

The learning rule prevents forgetting. Strengthening only the correct class's connections cuts forgetting from about 99% (backpropagation, error-driven readouts) to about 5%, and it works as well on raw pixels as on the expansion.

Sparse coding helps when a class has several shapes. With two-shape classes, sparse expansion beats raw pixels and non-sparse expansion by about 5–7 points. With ordinary digits it adds nothing.

The fly's specific wiring adds nothing measurable. Measured, shuffled, random sparse and dense random expansions perform within noise of each other, with measured wiring slightly behind. About 6% of the measured Kenyon cells receive no projection-neuron input at all and never fire.

Assumed: pixel-to-PN assignment, the 5% threshold, both readout rules, learning rates, the digit tasks. Measured: the PN→KC edges and synapse counts.
